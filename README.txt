عبدالرحمن عطية — نسخة تطوير الموقع

ملف النشر الأساسي على GitHub Pages هو index.html.

ما تم تطويره في هذه النسخة:
1) شاشة تحميل افتتاحية تحمل صورة صاحب الموقع والاسم مع حركة جرافيك خفيفة، وتختفي بعد اكتمال تحميل الصفحة (مع مهلة أمان).
2) تحسين الشريط العلوي وروابط التنقل والتفاعلات الدقيقة مع الحفاظ على الألوان والهوية الحالية.
3) حذف الجمل العامة التي كانت تخبر زوار الموقع بوجود لوحة إدارة أو إمكانية تعديل المحتوى منها.
4) حذف الجملة التجريبية أسفل عنوان «معرض الأعمال».
5) تطوير عارض صور «رؤية المزيد»: عرض الصور الأصلية من رابط التخزين دون ضغط أو إعادة تحجيم من كود الموقع، مع تكبير/تصغير وتنقل بين الصور وإغلاق بالكيبورد.
6) تحسين تحميل صور بطاقات الأعمال باستخدام lazy loading.
7) إضافة مراقبة للعناصر الديناميكية الجديدة حتى تطبق عليها الترجمة المحلية عند اختيار الإنجليزية.
8) الإبقاء على لوحة الإدارة الحالية ووظائفها: بيانات الموقع، المهارات، الخدمات، الأقسام، الأعمال وصورها، الخبرات، الآراء، الرسائل، والمستخدمون/الطلبات بحسب الوحدات الموجودة في المشروع.

حدود مهمة يجب معرفتها:
- الترجمة محلية داخل الموقع ولا تستخدم Google Translate. هي ترجمة قاموسية للنصوص والعبارات المضافة إلى قاموس الموقع. لا يمكن ترجمة أي نص جديد حر يكتبه المدير ترجمة بشرية دقيقة تلقائيًا دون إضافة ترجمته للقاموس أو ربط محرك ترجمة مستقل.
- إضافة الأقسام الموجودة مدعومة من لوحة الإدارة، لكن إنشاء أنواع أقسام برمجية جديدة بالكامل أو تغيير ترتيب كل أقسام الصفحة ليس نظام CMS مفتوحًا بعد.
- رفع صور المعرض الحالي يعتمد على Firebase Storage الموجود في المشروع. الرفع يتم باستخدام الملف الأصلي عبر uploadBytes ولا يضغطه كود الموقع؛ يلزم تفعيل Storage ونشر storage.rules. Firestore وحده لا يصلح لتخزين صور أصلية كبيرة بأمان بسبب حد حجم المستند.
- لا يمكن تأكيد عمل رفع/حذف الصور أو تسجيل الدخول قبل اختبار إعدادات Firebase الفعلية والحساب الإداري والقواعد المنشورة.

قبل النشر:
1) ارفع index.html وملفات الصور وملفات JSON إلى نفس مستودع GitHub Pages.
2) فعّل Firebase Storage في مشروعك إن لم تكن مفعّلة.
3) انشر firestore.rules داخل Firestore Database > Rules.
4) انشر storage.rules داخل Storage > Rules.
5) اختبر تسجيل الدخول، حفظ البيانات، رفع صورة غلاف، رفع عدة صور للمعرض، فتحها وتكبيرها، ثم حذف صورة.

ملاحظة: ملف index_scroll_fix.html نسخة احتياطية/بديلة وليس ملف النشر الأساسي. استخدم index.html.
