نسخة محدثة لموقع عبدالرحمن عطيه

أهم التعديلات:
- اللوجو دائري وواضح واسم عبدالرحمن عطيه أزيل من الشريط العلوي.
- لوحة تحكم موسعة: بيانات الموقع، المهارات، الخدمات، الأقسام والأعمال، الخبرة، الآراء، طلبات التواصل، الحسابات، المحادثات، وتغيير كلمة مرور الإدارة.
- رفع الصور من لوحة التحكم عبر Firebase Storage.
- صور تجريبية مؤقتة للأعمال لحين رفع الأعمال الحقيقية.
- الوضع الفاتح والداكن مضبوطين.

مهم للأمان:
- كلمات مرور العملاء لا يتم عرضها في لوحة الإدارة ولا يجب تخزينها كنص عادي. يمكن إدارة الحسابات عبر Firebase Authentication.
- دخول الإدارة يظهر حقل كلمة مرور فقط؛ البريد الإداري مخفي داخل الكود ولا يظهر للزوار.
- يجب أن يكون حساب الإدارة موجوداً في Firebase Authentication بالبريد الإداري المحدد في index.html حتى يعمل الدخول.
- طبّق firestore.rules وstorage.rules في Firebase Console.
- فعّل Authentication > Email/Password، Firestore Database، وStorage.

بعد الرفع على GitHub Pages قد تحتاج دقائق لظهور التحديث.
