# نسخة موقع عبدالرحمن عطية — النسخة المعدلة

هذه النسخة مبنية على الموقع الذي تم إرساله، وتم ترتيب وتحسين الأجزاء الأساسية بدون تغيير هوية التصميم.

## أهم ما تم تعديله
- قائمة حساب العميل من زر الثلاث نقاط: تسجيل الدخول / إنشاء حساب.
- إنشاء حساب بالاسم + الهاتف + البريد + كلمة المرور.
- تسجيل الدخول بالبريد أو الاسم أو رقم الهاتف.
- ملف شخصي للعميل.
- مراجعات العملاء مع ظهورها مباشرة للجميع وإمكانية حذفها من لوحة الإدارة.
- إدارة الخدمات: إضافة / تعديل / حذف.
- إدارة الأعمال: إضافة / تعديل / حذف، مع اختيار صورة من الجهاز ورفعها إلى Firebase Storage.
- إدارة الرسائل من لوحة الإدارة والرد على العملاء.
- حفظ تعديلات بيانات الموقع على Firestore بدل الاعتماد على localStorage فقط.
- شريط متحرك: «عبدالرحمن عطية • مصمم جرافيك».
- قواعد Firestore وStorage مقترحة ومحمية بحيث لا يستطيع الزوار الكتابة في بيانات الإدارة.

## قبل النشر
الموقع يستخدم Firebase الموجود أصلًا داخل `index.html` للمشروع:
`abdelrahman-website-98d4c`

من Firebase Console تأكد من:
1. Authentication → Sign-in method → Email/Password = Enabled.
2. Firestore Database = Enabled.
3. Storage = Enabled.
4. انسخ محتوى `firestore.rules` إلى قواعد Firestore.
5. انسخ محتوى `storage.rules` إلى قواعد Storage.
6. حساب المدير يجب أن يكون:
   `abdelrahmanatia167@gmail.com`
   وأن يكون موجودًا في Firebase Authentication.

## النشر على GitHub Pages
استبدل `index.html` والصور الموجودة في الريبو بهذه الملفات، وارفع `firestore.rules` و`storage.rules` للاحتفاظ بها كمرجع/استخدامها مع Firebase.
