نسخة V4 - تحديث الموقع

تم الحفاظ على شكل النسخة السابقة مع إصلاحات وتحسينات:
- زر اللغة EN/عربي يعمل على عناصر واجهة الموقع ويُعاد تطبيقه بعد فتح الصفحات الداخلية ولوحة التحكم.
- تسجيل الدخول يدعم البريد الإلكتروني أو الاسم أو رقم الهاتف بعد إنشاء/تحديث فهرس loginIndex.
- المحادثة المباشرة مرتبطة بحساب العميل وتستخدم Firebase Firestore.
- لكل تخصص صفحة داخلية تعرض الأعمال الخاصة به، ويمكن إدارة الأقسام والأعمال من لوحة التحكم.
- أضيفت منطقة مستقلة لحسابات السوشيال بعيدًا عن بيانات التواصل.
- آراء العملاء تستخدم تقييم 1 إلى 5 نجوم.
- Light/Dark مع رسوم خلفية متحركة في الحالتين.

مهم بخصوص كلمات المرور:
لا يمكن للموقع عرض كلمات مرور العملاء الأصلية. Firebase Authentication لا يعيد كلمة المرور للموقع حتى لو كنت مدير الموقع. لوحة التحكم تعرض بيانات الحساب وتوفر إرسال رابط إعادة تعيين كلمة المرور.

بعد رفع الملفات إلى GitHub:
1) انشر firestore.rules الجديدة.
2) انشر storage.rules.
3) فعّل Firebase Authentication -> Email/Password.
4) فعّل Firestore وStorage.
5) لو عندك عملاء قدامى قبل هذه النسخة، افتح لوحة التحكم > الأشخاص المسجلون واضغط "تحديث تسجيل الدخول بالاسم والهاتف" مرة واحدة.
