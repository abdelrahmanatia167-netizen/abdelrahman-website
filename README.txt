عبدالرحمن عطية — V14 (محدّثة)

تم الحفاظ على ملف الموقع وتصميم V14 الأساسي، وإجراء تحسينات وظيفية:
1) نظام ترجمة محلي داخل الموقع (قاموس عربي/إنجليزي مدمج في JavaScript)، دون Google Translate أو خدمة ترجمة خارجية.
2) تعزيز تفاعلات الضغط مع احترام إعدادات تقليل الحركة في الجهاز.
3) زر «رؤية المزيد» يفتح معرض القسم المرتبط بالعمل، ويعرض الصور الإضافية المرفوعة فقط؛ صورة الغلاف لا تظهر داخل معرض القسم. زر تفاصيل العمل يفتح صفحة العمل وصوره الإضافية.
4) صفحة التخصص تعرض صور المعرض الإضافية لكل عمل، وتدعم فتح تفاصيل العمل.
5) إضافة زر لحذف محادثة العميل بالكامل من لوحة الإدارة بعد تأكيد المستخدم. حذف الرسائل يتطلب صلاحيات الإدارة في Firestore.
6) فصل تسجيل العملاء عن مدخل الإدارة؛ العميل يسجل ويدخل بالبريد الإلكتروني وكلمة المرور فقط. بريد الإدارة مرفوض من نموذج العملاء، ولا يعرض نموذج العميل معلومات الإدارة.
7) تم التحقق من صحة بناء جملة JavaScript باستخدام Node.js.

النشر:
- ارفع ملفات ZIP إلى جذر مستودع GitHub Pages مع الاحتفاظ بصور الموقع وقواعد Firebase.
- انشر firestore.rules من هذه الحزمة في Firebase Console > Firestore Database > Rules حتى تعمل صلاحيات الإدارة وحذف المحادثات.
- احتفظ بقواعد Storage الحالية ما دامت تسمح بالمسارات site/ و projects/covers/ و projects/gallery/.
- بعد النشر، اختبر تسجيل العميل، رفع الصور، فتح المعارض، الرد على محادثة وحذفها بحساب الإدارة.

ملاحظات مهمة:
- ملف الموقع يعتمد على مشروع Firebase الموجود في الإعدادات الحالية. لا يحتوي هذا التعديل على بيانات اعتماد سرية للخادم؛ مفاتيح إعداد Firebase للويب ليست بديلاً عن قواعد الأمان.
- حذف سجل العميل من Firestore لا يحذف حساب Firebase Authentication نفسه؛ حذف حساب المصادقة بشكل إداري يتطلب Cloud Function أو Firebase Admin SDK على خادم آمن.
- لا يمكن ضمان أن كل إعداد خارجي في Firebase صحيح دون اختبار المشروع الحي بحساباتك. يجب نشر قواعد Firestore واختبارها بعد الرفع.


مهم: إصلاح رفع صور معرض الأعمال يعتمد على Firebase Storage أيضاً. انشر ملف storage.rules من هذه الحزمة في Firebase Console > Storage > Rules، وانشر firestore.rules في Firestore Database > Rules. يجب أن يكون المستخدم مسجلاً بحساب الإدارة المحدد داخل الكود. لا يمكن رفع الصور من GitHub Pages وحده إذا كانت قواعد Firebase غير منشورة أو كانت خدمة Storage غير مفعّلة.
