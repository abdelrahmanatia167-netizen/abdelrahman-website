عبدالرحمن عطيه — V15

التعديلات في هذه النسخة:
1) إصلاح رد الإدارة داخل الشات: يتم التأكد من جلسة حساب الإدارة وتحديث Firebase ID Token قبل إرسال الرد، والرد يُحفظ كرسالة جديدة داخل نفس محادثة العميل.
2) إصلاح رفع صور الأعمال: الرفع يتم إلى Firebase Storage داخل projects/covers وprojects/gallery مع contentType وcacheControl واسم ملف آمن، ثم تُحفظ بيانات الصور في projectImages لعرضها في المعرض.
3) رسائل أخطاء Firebase أصبحت واضحة بدل رسالة عامة مثل «تعذر إرسال الرد»، لتحديد مشكلة الصلاحيات أو المساحة أو الاتصال.
4) إضافة تبويب «نصوص الموقع» داخل لوحة التحكم لتعديل مجموعة النصوص الأساسية الظاهرة للزوار مع الحفاظ على ترتيب وتصميم الموقع.
5) إضافة لمسة جرافيكية عصرية خفيفة: شبكة خلفية، عناصر هندسية متحركة، لمعان للأزرار، تحسين الظلال وحالات الرفع، مع الحفاظ على الديزاين العام والألوان والبنية.
6) الحفاظ على نظام معرض الأعمال الحالي: صورة رئيسية للتفاصيل + صور إضافية لرؤية المزيد.
7) تحسين حماية عمليات الإدارة قبل الحفظ والرفع والحذف.

مهم بعد رفع النسخة على GitHub:
- انشر firestore.rules وstorage.rules الموجودين في هذه النسخة على مشروع Firebase نفسه.
- بعد نشر القواعد، سجّل خروج من لوحة الإدارة ثم ادخل مرة أخرى حتى يتم تحديث جلسة الإدارة.
- صور الأعمال الجديدة ستظهر في Firebase Storage تحت مجلد projects، وتُربط ببيانات Firestore في collection اسمها projectImages.
