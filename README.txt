نسخة V9 - Firebase Fixed

مهم جدًا:
1) افتح Firebase Console > مشروع abdelrahman-website > Firestore Database > Rules.
2) استبدل القواعد الموجودة بالكامل بمحتوى ملف firestore.rules الموجود هنا.
3) اضغط Publish.
4) لو لوحة التحكم ترفع صور: افتح Storage > Rules واستبدل القواعد بمحتوى storage.rules ثم Publish.
5) لا تحتاج لعمل قاعدة بيانات جديدة؛ Firestore الظاهر في المشروع بالفعل هو المطلوب.
6) بعد نشر القواعد، افتح الموقع وسجل دخول الإدارة ثم جرّب تعديل أي نص من لوحة التحكم.
7) المفروض يظهر التعديل للزائر تلقائيًا من Firestore بدون إعادة رفع GitHub.

ملاحظة:
- كلمات مرور العملاء لا يمكن عرضها من لوحة التحكم لأن Firebase Authentication لا يعيد كلمة المرور الأصلية.
- البريد الإداري لا يظهر للزوار داخل الموقع.
- GitHub Pages مطلوب فقط عند تغيير كود الموقع نفسه، وليس عند تعديل المحتوى من لوحة التحكم.
